# 叫我罗城主（阶段 0 原型）

一个纯前端的离线放置增量游戏原型，题材取自《吞噬星空》。
**个人同人练习作，仅供自己手机安装使用，请勿公开分发。**

## 目录结构

```
luo-chengzhu/
├─ index.html      界面结构
├─ style.css       样式
├─ game.js         全部游戏逻辑（数值都在文件顶部「配置区」）
├─ manifest.json   PWA 清单，让 Chrome 认它是可安装应用
├─ sw.js           Service Worker，负责离线缓存
├─ icons/          图标（192 / 512）
└─ docs/           设计文档（PRD）
```

## 本地预览

直接双击 `index.html` 就能在电脑浏览器里玩。
（`file://` 下 Service Worker 不生效，但游戏本身照常运行。）

## 部署到手机（Android）

全程不需要命令行、不需要 git、不需要装任何开发工具。

**路线 A：Cloudflare Drop（最快，可以先不注册账号）**

1. 打开 <https://cloudflare.com/drop>，把整个 `luo-chengzhu` **文件夹**拖进浏览器窗口。
2. 几秒后得到一个临时的 `https://xxx.workers.dev` 网址（**只保留 1 小时**）。
3. 想长期用，必须在 1 小时内点 **Claim**，登录或注册一个免费 Cloudflare 账号把站点认领到自己名下，链接才永久保留。
   （注意：新注册账号要先验证邮箱，这一步别拖到最后一刻。）
4. 手机 Chrome 打开该网址 → 右上角菜单 → **「安装应用」/「添加到主屏幕」**。
5. 以后从桌面图标进入，无地址栏、全屏，断网也能玩。

**路线 B：Netlify Drop** —— 打开 <https://app.netlify.com/drop> 拖文件夹，流程类似。

**路线 C：GitHub Pages（最稳，但步骤多）** —— 建仓库 → 网页端直接拖文件上传 → Settings → Pages → 选 main 分支发布。

> 为什么必须走一次托管？因为 Service Worker（离线缓存）和「安装到主屏幕」都要求
> HTTPS 环境。装好之后它就是本地的，跟服务器再没关系了。

## 改了代码怎么更新

> **当前状态**：手机上装的是首次临时部署的版本，那个 `workers.dev` 网址已失效且没认领过，
> 所以手机里的那份是唯一一份（存档也在手机里）。改代码不受影响，源码都在本目录。

> ⚠️ `workers.dev` 在国内被阻断，**只有更新时需要开一次加速器**，日常玩游戏不用。

1. 改完代码，把 `sw.js` 里的 `CACHE = 'lcz-v1'` 改成 `lcz-v2`（**每次都要 +1**，否则手机永远命中旧缓存，改了像没改）。
2. 先在手机上旧版游戏里**导出存档**：右上角 💾 → 导出 → 复制 → 存到微信文件传输助手。
3. 电脑上重新部署：把 `luo-chengzhu` 文件夹拖到 <https://cloudflare.com/drop>。
4. 上传完成后**立刻点页面上的 Claim 认领**，登录免费 Cloudflare 账号把它变成永久网址。
   **不要像第一次那样直接退出**——临时预览只保留 1 小时，退出后就找不回来了。
5. 手机开加速器 → Chrome 打开新网址 → 添加到主屏幕。
6. 在新游戏里导入第 2 步的存档码（💾 → 粘贴 → 导入）。
7. 删掉桌面上旧的快捷方式。

第 4 步认领成功后，网址就是永久的了，以后更新只需重复 1、2、6，再加上"在 Cloudflare 控制台
上传新文件覆盖"，不必每次换网址。

## 想调数值 / 改设定

全部集中在 `game.js` 顶部：

- `PRODUCERS`：生产单位的名称、图标、基础成本、成本增长率、每秒产出。
- `UPGRADES`：升级项。`type` 支持 `clickAdd`（点击加法）、`clickMult`（点击乘法）、`globalMult`（全局产出乘法）。
- `REALMS`：境界名称与解锁阈值。**这里的境界名是占位，请按你自己的记忆校对修改。**
- `OFFLINE_EFFICIENCY` / `OFFLINE_CAP_HOURS`：离线收益效率与上限。
